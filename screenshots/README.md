# حالة لقطات المعاينة

تعذر التقاط لقطات الموقع في جلسة التنفيذ الحالية لأن أداة المتصفح المدمجة أعادت قائمة متصفحات فارغة `[]` في محاولتين، حتى بعد إجراء تشخيص الاتصال الموصى به.

لم توضع صور بديلة أو لقطات مصطنعة مكان نتائج الاختبار. عند توفر جلسة Browser، يجب التقاط الصفحة الرئيسية بالتركيبات الآتية قبل الإطلاق:

- العربية — نهاري وليلي — 360 و768 و1440 و1920 بكسل.
- الإنجليزية — نهاري وليلي — 360 و768 و1440 و1920 بكسل.
- لوحة التحكم — 1440 بكسل.

نتائج الاختبارات الآلية المنفذة موثقة في `QA-REPORT.md`.
